# Quick Start

## Prerequisites

- [Docker](https://www.docker.com/get-started) with Docker Compose
- [.NET 10 SDK](https://dotnet.microsoft.com/download) for local development
- Git

## Run the complete environment

```bash
git clone https://github.com/therissole/symphony-test-1.git
cd symphony-test-1
docker compose up --build -d
docker compose ps
```

Docker Compose starts:

- PostgreSQL 18 on port `5432`
- Flyway 13, which applies migrations once
- The API on port `8080`

Check the application:

```bash
curl http://localhost:8080/api/health
curl http://localhost:8080/api/languages
curl "http://localhost:8080/api/greetings/by-language/en?formal=true"
```

The Development OpenAPI document is available at:

```text
http://localhost:8080/openapi/v1.json
```

To avoid host port collisions, set `SYMPHONY_API_PORT` or `SYMPHONY_POSTGRES_PORT` before
starting Compose. Their defaults are `8080` and `5432`.

To stop the environment and delete its local database volume:

```bash
docker compose down -v
```

## Run the API from the SDK

Use Docker only for PostgreSQL and migrations:

```bash
docker compose up -d postgres flyway
dotnet run --project src/symphony-test-1.Api
```

The Development connection string targets `localhost:5432`. Docker Compose overrides it with the
internal `postgres` host when the API runs in a container.

## Run tests

Docker must be running because integration and end-to-end tests create isolated PostgreSQL
containers.

```bash
dotnet test symphony-test-1.slnx
```

Run suites individually:

```bash
dotnet test tests/unit/symphony-test-1.UnitTests/symphony-test-1.UnitTests.csproj
dotnet test tests/integration/symphony-test-1.IntegrationTests/symphony-test-1.IntegrationTests.csproj
dotnet test tests/e2e/symphony-test-1.E2ETests/symphony-test-1.E2ETests.csproj
```

## Verify reference quality

```bash
dotnet format symphony-test-1.slnx --verify-no-changes
dotnet build symphony-test-1.slnx --configuration Release
dotnet test symphony-test-1.slnx --configuration Release --no-build
dotnet list symphony-test-1.slnx package --vulnerable --include-transitive
```
