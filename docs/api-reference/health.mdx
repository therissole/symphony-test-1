# Health API

## GET /api/health

Checks whether the API can open a PostgreSQL connection and execute `SELECT 1`.

### Healthy response

`200 OK`

```json
{
  "status": "Healthy",
  "database": "Connected",
  "timestamp": "2026-07-23T10:00:00Z"
}
```

### Unhealthy response

`503 Service Unavailable`

```json
{
  "status": "Unhealthy",
  "database": "Unavailable",
  "timestamp": "2026-07-23T10:00:00Z"
}
```

The API logs the underlying failure but deliberately does not expose connection strings, server
details, or exception messages in the response.

```bash
curl http://localhost:8080/api/health
```

Docker Compose uses this endpoint as the API container health check. It is a dependency-aware
readiness signal, not a process-only liveness probe.
